# YMM4台本エディタ — LLM 向け 台本 Markdown フォーマット仕様

このドキュメントは、**ChatGPT などの LLM に台本を書いてもらうための「出力フォーマット指示書」**です。
ここに書かれた形式で出力された Markdown は、YMM4台本エディタの「**読込 ▸ .md を読み込む**」でそのまま取り込めます。

> 使い方:
> 1. このドキュメントの内容（または末尾の「貼り付けテンプレート」）を LLM に渡す。
> 2. LLM が出力した Markdown を `.md` ファイルとして保存（または既存の `.md` に貼り付け）。
> 3. アプリのヘッダー「読込 ▾」→「.md を読み込む」で取り込む。読み込み時は**現在の台本を置き換え**ます。

---

## 1. 最重要ルール（これだけは厳守）

1. **1行 = 1セリフ**。形式は次のとおり:

   ```
   キャラクター名: セリフテキスト
   ```

2. 区切りは **半角コロン `:` ＋ 半角スペース1つ**（`: `）。
   - ✅ `霊夢: こんにちは`
   - ❌ `霊夢：こんにちは`（**全角コロン「：」はダメ** → その行は無視される）
   - ❌ `霊夢:こんにちは`（**コロン直後の半角スペースが無い** → その行は無視される）

3. **セリフは1行に収める**。1つのセリフを改行で分けない（改行すると別の行＝別セリフ扱い）。

4. **空行は無視される**。読みやすさのために自由に空行を入れてよい。

5. **`#` で始まる行は無視される**（コメント・見出し用）。章タイトルやメモに使えるが、**セリフ行の先頭に `#` を付けない**こと。

6. **行頭・名前に Markdown 装飾を付けない**。箇条書き（`- ` `* `）・太字（`**`）・引用（`> `）・番号（`1. `）などは、名前の一部と誤解釈されて壊れる。
   - ❌ `- 霊夢: やあ`（先頭の `- ` のせいで名前が「- 霊夢」になる）
   - ❌ `**霊夢**: やあ`（名前が「\*\*霊夢\*\*」になる）

7. キャラクター名は**最初の `: ` より前すべて**。スペースを含んでよい（例: `ナレーター（影）: …`）。名前自体に `: `（コロン＋半角スペース）を含めないこと。

> 補足: セリフ本文に句読点・記号・絵文字・半角コロンを含めても問題ありません（分割は**最初の `: ` 1回だけ**）。
> 例 `霊夢: 時刻は 12:00 だよ` → 名前「霊夢」／セリフ「時刻は 12:00 だよ」。

## 2. フロントマター（任意・あると親切）

台本本文の前に `---` で囲んだブロックを置くと、プロジェクト名とキャラクター（色つき）を明示できます。**省略しても動きます**。

### 2.1 完全形式（フロントマターあり）

色やキャラ定義を正確に渡したいときに使う。

```markdown
---
project: 第1回 解説動画
characters:
  - name: 霊夢
    color: "#FF6B6B"
  - name: 魔理沙
    color: "#FFB347"
  - name: ナレーター
---

霊夢: 今日は YMM4 の使い方を解説するわよ！
魔理沙: しっかり覚えろよな！
ナレーター: まずはプロジェクトの作成から始めましょう。
```

- `project:` … プロジェクト名（省略可）。
- `characters:` … キャラ定義のリスト。各キャラは `  - name: 名前` の行、必要なら次行に `    color: "#RRGGBB"`（**色は省略可**。省略時は自動で色が付く）。
- 本文に**フロントマター未定義のキャラ**が登場したら、自動で追加登録される。

### 2.2 省略形式（フロントマターなし）

本文だけ。登場したキャラは**出現順に自動登録**され、色も自動で付く。LLM に手早く書かせるときはこれで十分。

```markdown
霊夢: 今日は YMM4 の使い方を解説するわよ！
魔理沙: しっかり覚えろよな！
霊夢: まずはここから始めるわ。
```

## 3. 完全な出力例

```markdown
---
project: CSVの使い方解説
characters:
  - name: 霊夢
    color: "#FF6B6B"
  - name: 魔理沙
    color: "#FFB347"
---

# イントロ（この行はコメント。読み込み時は無視される）
霊夢: 今日は YMM4 で CSV を読み込む方法を解説するわ。
魔理沙: 字幕を一気に流し込めるやつだな。

# 本編
霊夢: まずは「キャラクター名,セリフ」の形式で1行ずつ書くの。
魔理沙: 区切りはコンマ1個だぜ。
霊夢: そう。あとは YMM4 に読み込ませるだけ。
```

→ 取り込むと、霊夢・魔理沙の2キャラと6行のセリフになる（`#` の2行は無視）。

## 4. やりがちな失敗（NG 集）

| NG 例 | 何が起きるか | 正しい書き方 |
|---|---|---|
| `霊夢：やあ` | 全角コロン → 行が無視される | `霊夢: やあ` |
| `霊夢:やあ` | コロン後にスペースが無い → 無視される | `霊夢: やあ` |
| `- 霊夢: やあ` | 名前が「- 霊夢」になる | `霊夢: やあ` |
| `**霊夢**: やあ` | 名前に `**` が入る | `霊夢: やあ` |
| 長いセリフを<br>改行で分割 | 別々のセリフ行になる | 1セリフ＝1行に収める |
| `# 霊夢: やあ` | コメント扱いで消える | 先頭の `#` を外す |

> 形式が不正な行（`: ` を含まない行など）は**読み飛ばされ、取り込み後にスキップ件数が通知**されます。意図せず行が消えたらこの仕様を疑ってください。

## 5. そのまま LLM に貼り付けるテンプレート

```
以下のルールで YMM4 用の台本を Markdown で出力してください。

【キャラクター】
- 霊夢（ツッコミ役）
- 魔理沙（元気な解説役）

【テーマ】
（ここに動画のテーマを書く。例: 「YMM4でのCSV読み込み方法の解説」5往復程度）

【出力フォーマット（厳守）】
- 1行1セリフで「名前: セリフ」の形式。コロンは半角、直後に半角スペース1つ。
- 全角コロン「：」やスペース無しは禁止（読み込めない）。
- セリフは1行に収める（改行で分けない）。
- 箇条書き・太字・引用・番号などの装飾を行頭や名前に付けない。
- コメントや見出しを入れるなら行頭を「#」にする（読み込み時に無視される）。
- 先頭にフロントマターを付けてよい（任意）:
  ---
  project: タイトル
  characters:
    - name: 霊夢
      color: "#FF6B6B"
    - name: 魔理沙
      color: "#FFB347"
  ---
- コードブロックで囲まず、Markdown 本文だけを出力してください。
```

---

## 6. 補足（気にしなくてよいこと）

- セリフ内の**半角カンマ `,`** は、CSV 書き出し時にアプリが自動で全角カンマ「，」に変換します（列ズレ防止）。読点「、」はそのまま保持。LLM 側でカンマを避ける必要はありません。
- 文字コードや BOM などはアプリ側で処理します。LLM は普通の UTF-8 テキストを出せば OK。
- 取り込みは**現在の台本を置き換え**ます（追記ではありません）。
