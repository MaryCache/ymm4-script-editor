# 仕様追加書: Markdown対応 + コードブロックコピー

対象バージョン: v1.1.0
作成日: 2026-05-24
基底ドキュメント: requirements.md / design.md v1.0.0

---

## 1. 追加背景

AIが台本を生成・編集できるようにするため、Markdown形式での入出力を追加する。  
あわせて、各セリフ行をCSV形式のコードブロックで表示し、1行単位・全件単位でのコピーを可能にする。

---

## 2. Markdown フォーマット仕様

### 2.1 完全形式（フロントマターあり）

キャラクターの色情報を保持したい場合や、AIに正確なキャラクター定義を渡す場合に使う。

```markdown
---
project: 第1回解説
characters:
  - name: 霊夢
    color: "#FF6B6B"
  - name: 魔理沙
    color: "#FFB347"
  - name: ナレーター
    color: "#87CEEB"
---

霊夢: 今日はYMM4の使い方を解説するわよ！
魔理沙: しっかり覚えろよな！
ナレーター: まずはプロジェクトファイルの作成から始めましょう。
```

### 2.2 簡易形式（フロントマターなし）

AIが台本のみを出力する場合の最小形式。キャラクターは本文から自動登録される。

```markdown
霊夢: 今日はYMM4の使い方を解説するわよ！
魔理沙: しっかり覚えろよな！
ナレーター: まずはプロジェクトファイルの作成から始めましょう。
```

### 2.3 パース規則

| ルール | 内容 |
|---|---|
| 行形式 | `キャラクター名: セリフテキスト`（コロン＋スペース区切り） |
| キャラクター名 | コロン前のすべてのテキスト。空白を含んでよい |
| フロントマター | `---` で囲まれたYAMLブロック（省略可） |
| 空行 | 無視する |
| `#` で始まる行 | コメント・見出しとして無視する |
| フロントマターなしの場合 | 本文から出現したキャラクター名を順に自動登録。色は自動付与 |
| フロントマターありの場合 | `characters` の定義を優先。本文に未定義のキャラが出現した場合は自動追加 |

### 2.4 エクスポート規則

- 出力は常に「完全形式（フロントマターあり）」とする
- ファイル名: `{プロジェクト名}.md`
- 文字コード: UTF-8（BOMなし）

## 3. 追加機能要件

requirements.md への追記分。

### 3.1 Markdownインポート

| ID | 要件 | 優先度 |
|---|---|---|
| F-40 | `.md` ファイルを読み込んでプロジェクト状態に変換できる | 必須 |
| F-41 | フロントマターがない場合、本文からキャラクターを自動登録する | 必須 |
| F-42 | 既存プロジェクトへの追記インポートではなく、読み込み時は現在の状態を置き換える | 必須 |
| F-43 | パース失敗行（形式不正）はスキップし、スキップ数をインポート後に通知する | 推奨 |

### 3.2 Markdownエクスポート

| ID | 要件 | 優先度 |
|---|---|---|
| F-44 | 現在のプロジェクトを完全形式Markdownとして書き出せる | 必須 |

### 3.3 コードブロックコピー

| ID | 要件 | 優先度 |
|---|---|---|
| F-50 | 各セリフ行に「1行コピー」ボタンを設ける。クリックで `キャラクター名,セリフ` 形式をコピーする（既存F-20と統合） |  必須 |
| F-51 | ヘッダーまたはエディタ上部に「全件コピー」ボタンを設ける | 必須 |
| F-52 | 全件コピーの内容は、台本全行を `キャラクター名,セリフ` 形式で改行区切りにしたテキストとする | 必須 |

### 4.3 Header コンポーネント 変更点

- 「読込」ボタンを「読込▼」ドロップダウン化し、以下2つを展開
  - `.ymscript` を読み込む
  - `.md` を読み込む
- 「保存」ボタンを「保存▼」ドロップダウン化し、以下3つを展開
  - `.ymscript` として保存
  - `.md` として保存
  - CSV を書き出す（既存の「CSVエクスポート」を統合）
- 「全件コピー」ボタンを追加（CSV形式でクリップボードにコピー）

### 4.4 LineRow コンポーネント 変更点

既存の「1行コピー」ボタンの動作を以下に統一：
- クリックで `キャラクター名,セリフ` をクリップボードにコピー（既存動作と同一）
- コードブロック表示は **常時ではなく、行ホバー時のツールチップ** で表示する（UIノイズを抑える）

## 6. AIへのプロンプト例（参考）

このフォーマットを使えば、AIに台本生成を依頼したあとそのままインポートできる。

```
以下の形式でYMM4台本を書いてください。

キャラクター：
- 霊夢（ツッコミ役）
- 魔理沙（元気な解説役）

テーマ：YMM4でのCSV読み込み方法の解説（5往復程度）

出力形式：
霊夢: セリフ
魔理沙: セリフ
（フロントマターは不要）
```
